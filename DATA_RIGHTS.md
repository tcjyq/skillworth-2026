# Data Rights and Redistribution Boundary

## What this repository publishes

SkillWorth publishes its own source code, authored documentation, schemas, taxonomies, methodology, synthetic Demo fixtures, aggregate statistics and derived analysis outputs. The MIT license at the repository root applies only to SkillWorth-authored code and documentation.

## What it does not publish

The repository does not redistribute Freehire raw records, full job-description text, local source caches, Real-mode manifests, warehouses, Parquet exports or review recordings. A clone can run the Demo mode without those private local artifacts.

## Source attribution and uncertainty

The current China technical-job observation is a single supplementary sample obtained through Freehire's documented public API. The Freehire software license does not automatically license third-party recruitment content for bulk redistribution. The audited status `no_explicit_block_found` is not an assertion of an open recruitment-data license.

Other external datasets and software retain their respective licenses and terms. The project records attribution and source boundaries in [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md) and [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). External benchmark data remains separated from the core analysis unless the documented source gate permits its use.

## Reuse of published results

Published aggregates and derived metrics describe a frozen, limited sample. They are not a mirror of an upstream job board, a complete China job-market measurement, or a license to reuse third-party job content.
