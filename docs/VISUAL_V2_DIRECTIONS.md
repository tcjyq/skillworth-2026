# SkillWorth Visual V2 — Art Directions

## Direction A：Living Signal Field（活体信号场）

核心思想：页面只有一个持续存在的“数据舞台”。技能节点从首屏进入同一坐标场，随后在五个 Finding 中保持身份连续并改变排列。用户不是滚过五张图，而是看见同一份证据被逐层解释。

1. **Hero**：超宽问题标题与一个被切开的动态坐标场。Python / SQL / Git 不是 Hero KPI，而是远处尚未命名的三个数据光点；开始滚动后坐标轴与解释文字才出现。
2. **滚动**：桌面端主舞台在中部短距离 pin；右侧/下方证据句成为 waypoint。每个状态只改变最多两个视觉属性。移动端取消 pin，使用五个短场景。
3. **Data Frontier**：所有技能先形成全局散点，非目标 dim；Pareto 路径被“写出”，Python / SQL / Git 沿路径获得标签。
4. **C++ #3 → #35**：同一个 C++ 节点先在 Demand 纵轴上升到 #3，再通过坐标轴 morph 滑落至 SkillWorth #35；路径上出现 260h 学习投入注释。
5. **Role Reversal**：Kubernetes / Terraform / Spark / Kafka 保持同一位置身份，global 排名基线折叠为两条角色轨道，节点沿轨道滑入 DevOps / Data Engineer 新名次。
6. **Skill Synergy**：坐标轴淡出，节点保留并重组为 2D stack constellation；三条边分两类编码：absolute scale 与 relative affinity，hover 只突出邻域。
7. **Ranking Robustness**：节点收缩为排名区间带；Python / SQL / Git / Docker 是紧密核心，RAG / Tableau / Azure 的区间展开，精确名次文字主动淡出。
8. **Tool / exploration**：故事结束后舞台解除 pin，收束为一个明确的“进入 Lab”控制，不在叙事中插入 Dashboard。
9. **Desktop / Mobile**：桌面 60/40 舞台与注释；移动端每个状态生成独立静态图，点按可查看证据，路径动画改为 220ms crossfade。
10. **高级感来源**：连续对象与连续空间创造“认知镜头”，而不是背景特效；视觉冲击来自数据结构真正变化。

## Direction B：Evidence Cut（证据剪辑室）

核心思想：像一部克制的编辑式数据短片。大字命题、严格的分镜、连续图形剪辑和脚注式证据共同推进，强调研究可信度与文字节奏。

1. **Hero**：近黑背景上的两行问题标题；一条极细时间线穿过页面，第一屏只露出下一帧的三枚节点。
2. **滚动**：每屏是一帧，采用硬切 + 局部 morph；没有长距离 pin，滚动节奏更接近长篇数据新闻。
3. **Data Frontier**：散点像编辑图片一样占满画面，结论文字以边缘注释进入，不使用图表容器。
4. **C++ #3 → #35**：用一条从页面顶部穿到底部的排名胶片，#3 和 #35 是两个停格；C++ 在两帧之间下坠。
5. **Role Reversal**：同一张排名表被两次“重新排版”，DevOps 与 Data Engineer 像两版杂志版式切换。
6. **Skill Synergy**：三组 pair 作为三个横向满宽句子，连接线在字间生长；数据标签是脚注而非图例。
7. **Ranking Robustness**：稳健核心以窄区间排版锁定，长尾名称在宽区间中漂移，形成静态也清楚的对比。
8. **Tool / exploration**：末尾像刊物 colophon，提供 Methodology、Data Scope 与 Lab 入口。
9. **Desktop / Mobile**：天然单列，移动端可完整保留；大字比例与边缘注释重新排版。
10. **高级感来源**：强编辑控制、留白、排版与证据脚注，不依赖 GPU 或大量交互。

## Direction C：Stack Atlas（技能栈图谱）

核心思想：把技能市场看作可导航的二维知识空间。页面通过相机式平移和缩放在同一图谱上定位五个 Finding，强调探索感和技能组合。

1. **Hero**：全屏二维技能图谱，用户从远景看到全部节点，标题悬浮于未聚焦区域。
2. **滚动**：Scene Director 控制 2D camera 的 pan / zoom / focus；章节文字像地图标注进入。
3. **Data Frontier**：相机聚焦图谱左上区域，把效率前沿临时叠加成等高线。
4. **C++ #3 → #35**：相机追踪 C++ 从 demand layer 移向 value layer，以轨迹显示排名反转。
5. **Role Reversal**：图谱切换两层角色滤镜，四个角色技能位置变化并保留 ghost origin。
6. **Skill Synergy**：最适合此方向；相机进入三个局部网络，邻域高亮和 click-to-focus 强。
7. **Ranking Robustness**：相机拉远，节点变成区间云；稳定核心保持锐利，长尾失焦。
8. **Tool / exploration**：故事结束后直接解除导演控制，图谱变为可探索 Lab。
9. **Desktop / Mobile**：桌面交互强；移动端必须限制缩放与拖拽，并提供列表替代入口。
10. **高级感来源**：空间导航与数据地图隐喻具有记忆点，但对少量冻结关系数据存在过度表达风险。

## 选择

**Primary：Living Signal Field。** 虽然 Evidence Cut 的综合风险分更优，但 Visual V2 的首要目标是让动画帮助用户理解同一批数据如何改变含义。Living Signal Field 对“连续身份、布局 morph、focus / dim、同一对象跨 Finding”解决得最彻底，也最能修复现版的 Section 页面感。

## V2.1 人工体验后的方向修正

真实用户体验证明，Living Signal Field 虽然改善了连续性，却让节点系统压过了结论、可读性与权威感。V2.1 因此不受既有实现成本约束，将主方向改为 **Editorial Evidence Field**：以 Evidence Cut 的编辑层级为基础，只在 C++ 排名落差和角色重排保留沉浸式连续转换。完整批评与修正依据见 `docs/VISUAL_V2_1_CORRECTION.md`。

**Backup：Evidence Cut。** 如果真实浏览器 QA 发现 pinning、低端设备或移动端使主方向的认知收益不足，就退回此方向。它仍能显著提升编辑感与数据叙事，而且静态降级最可靠。

Stack Atlas 不进入原型：冻结的 synergy 只有三组关系，空间图谱会暗示比证据实际支持范围更大的网络结构。
