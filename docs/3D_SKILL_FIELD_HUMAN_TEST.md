# 3D 技能星域第一次使用理解测试

## 目的与参与者

验证第一次看到 `/lab/3d-skill-field` 的人能否理解远近、排名变化和技能共现。招募 3～5 名未参与项目的普通大学生、应届生、朋友或同学。不要提前解释图的规则，也不要把教学后的答案计为成功。

测试使用 production build 与冻结 Real v6：近 180 天、998 个岗位、313 家公司、134 项观测技能。逐人单独测试；征得同意后才录音或录屏，不记录无关个人信息。

## 主持原则

- 只读任务文字，不解释答案，不暗示搜索框或目标技能位置。
- 用户沉默时最多问“你现在在想什么？”，不提供方向。
- 点错、犹豫、返回、放弃均如实记录。
- 任务结束后才追问误解原因；不得回填或美化结果。

## 任务

### 1. 价值核心（5 秒）

展示全局学习性价比星域 5 秒后暂停操作，问：“你觉得离中间更近代表什么？”

通过：主动表达“更值得学 / 优先级更高 / 更值得关注”等同义意思。

### 2. C++ 排名反转

让参与者切到“只看招聘需求”，问：“C++ 怎么了？”再切回“学习优先”，重复提问。

通过：说出 C++ 需求排名高，但考虑学习投入后排名明显下降；最好能读出 `#3 → #35`。

### 3. DevOps 职业变化

让参与者选择 DevOps，问：“哪些技能明显变重要了？”

通过：至少主动注意到 Kubernetes；最好同时注意到 Terraform，并理解 `#18 → #1`、`#33 → #3` 是全局到职业内的排名变化。

### 4. Python–SQL 关系

让参与者搜索 Python，问：“哪个技能和 Python 关系最明显？”让其选择 SQL，再问：“这条关系线告诉你什么？”

通过：表达“经常一起出现 / 很多岗位同时提到”；若理解成因果、先后学习顺序或必修关系则失败。

### 5. 自主寻找 Kubernetes

要求：“请你自己找到 Kubernetes。”不提示方法。

观察：是否自然使用搜索框，而不是在 134 个球中逐个寻找。记录首次有效操作、完成时间与错误路径。
